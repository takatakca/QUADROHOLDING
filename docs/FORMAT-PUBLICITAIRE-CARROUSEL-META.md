## L'instruction

**Le format par défaut de nos publicités Meta est le CARROUSEL défilant** : une suite de cartes horizontales que l'utilisateur fait défiler, **UNE image par section** :

1. **Une carte = une section.** Chaque carte montre UNE chose : un service, une section du dashboard, ou une famille de plats. Titre court en gros caractères sur l'image (2–3 mots, style des cartes de référence : « MANAGE JOBS », « GROW REVENUE ») + bouton/lien cliquable propre à cette carte.
2. **Application TAKATAK / Tac Attack (dashboard et services)** : une carte par service/section — par exemple : Marketing réseaux sociaux · Sites web · Hébergement · Téléphonie AI (Phone AI) · Avis clients (TAKATAK Review) · Réservation en ligne — chaque carte mène à la section ou à la page d'inscription correspondante.
3. **Application RESTAURANTS** : une carte par section du menu / famille de plats — chaque carte = un plat ou une famille différente (pizzas, poutines, pitas, desserts…), avec les **vraies photos officielles** de la marque. On fait défiler le menu, carte par carte.
4. **Règles permanentes qui continuent de s'appliquer** :
   - La pub porte l'**offre + un lien cliquable** ; **jamais de prix** dans le texte publicitaire.
   - Créatifs = **notre production originale** (photos réelles des marques, exports Canva officiels) ; les captures de concurrents sont une référence de format seulement, jamais un créatif.
   - Aucune pousse payante sans les budgets fixés par Matt.
   - FR / EN selon la campagne.
5. **Propriétaires** : SOCIO produit et publie les carrousels sociaux/publicitaires ; chaque agent qui prépare une pub Meta (restaurants = Lévesque, autres entreprises = LesGroupes) applique ce format par défaut et le note selon la méthode avant–pendant–après, signé de son nom.
